Xrash 0.5.8 is built with icli 1.0.0.

- The device state that Report Crash collects on a jailbroken iPhone or iPad (launchd services, apps, processes, tweaks and jetsam) is read with icli 1.0.0 instead of 0.8.2. The parts of icli that Xrash uses only gained additions in between, so the Collected Files are the same as before.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.5.8-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
