Xrash 0.4.8 no longer crashes while drawing app icons.

- On some devices, iOS 18.3.1 among them, the report list could crash as soon as it drew an app's icon: the crash was in the system's own icon renderer, before any icon appeared. Xrash now reads each icon from the files in the app's bundle instead of asking the system to draw it. An app that ships no icon file keeps the row's own artwork.
- The icon at the top of a report is the same picture as the list's. On an iPhone, where apps ship icons smaller than that space, it can look slightly softer than before.
- A report whose app runs from a link to a file outside its bundle shows that app's icon again.
- On a Mac, an app's icon is scaled to the size Xrash draws it as it is read, rather than kept in memory at full size.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.4.8-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
