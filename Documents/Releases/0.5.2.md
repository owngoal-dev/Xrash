Xrash 0.5.2 prepares a data folder of its own when it is installed.

- Installing the package now creates `Documents/wiki.qaq.xrash` for mobile — and `Documents` itself where the bootstrap had none — so Xrash has a folder no other app writes into, as a sandboxed app would. Nothing else changes.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.5.2-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
