Xrash 0.5.1 improves report browsing, text search, and saved report layouts, with smaller downloads.

- Report text search now has clearer controls, match navigation, and highlights.
- Report lists preserve selection across navigation and refresh when their data changes. Cached report metadata makes repeated loading more efficient.
- Refined report filters, count badges, date labels, and loading states, along with report details, saved report cards, bundle details, and crash report editing.
- Missing-symbol rows are simpler, binary names keep their original case, and duplicate suspect rows are removed.
- Notification authorization is checked again when the app returns to the foreground. Settings layouts are refined, and license text opens at the top.
- Smaller release packages use a trimmed Runestone editor and optimized asset catalogs.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.5.1-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
