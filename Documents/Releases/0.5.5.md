Xrash 0.5.5 opens on iOS 15 again.

- On iOS 15, Xrash 0.5.4 quit as soon as it opened. icli 0.8.0, which it was built with, needed a system function that arrived in iOS 16. Xrash is now built with icli 0.8.2, which looks that function up only where it exists, so the app and its notifications work on iOS 15 as they do on later versions.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.5.5-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
