Xrash 0.4.7 builds again with Xcode 27. Nothing changes in how the app behaves.

- Zip reading and writing now use libarchive.xcframework 1.0.0, whose Swift module is named ArchiveKit. The old name, LibArchive, differed from the C library's only by case, and on a case-insensitive disk Xcode 27 refused to load it. The libarchive binary is the same one 0.4.6 shipped.
- The system-state tools come from icli 0.6.9, which uses the same libarchive and carries icli's fixes since 0.5.0.
- The Mach-O reader is no longer held to swift-fileio 0.14: MachOKit builds against 0.15 now.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.4.7-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
