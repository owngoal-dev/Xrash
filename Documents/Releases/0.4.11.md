Xrash 0.4.11 asks for access to the graphics processor, so iOS features that draw with it cannot close the app.

- iOS draws app icons, Bold Text and the share sheet with the graphics processor, even in an app that draws nothing with it itself. Inspector closed at launch for lack of this access; Xrash now asks for it too, with the same list as the other OwnGoal apps.
- Every package is now checked for that access before it is published, so a build without it is not released.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.4.11-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
