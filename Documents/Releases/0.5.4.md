Xrash 0.5.4 is built with icli 0.8.0. Nothing changes in how the app behaves.

- The system-state tools come from icli 0.8.0. The half Xrash links reads system state the same way it did in 0.7.16; the changes in between are to the code that registers apps and expands archives, which Xrash does not link.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.5.4-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
