Xrash 0.5.3 is less than two thirds the size to download, acts on every report of a process you select, and stops blaming images it cannot name.

- The RootHide package was 5.0 MB, 2.0 MB of it six large copies of the app icon. The icon now ships as three compressed images, and the package is 3.0 MB. It looks the same on the Home Screen in Default, Dark, Clear and Tinted; it no longer moves with the light the way the layered glass icon did.
- With reports grouped by process, selecting a process and deleting or marking it read did nothing to its reports. It now acts on every report of that process the current filter shows, and a process page whose last report you cleared goes back to the list instead of staying empty.
- A crash could list a loaded image with no name and no path among its suspects. Such an image is no longer suspected; one with only a name or only a path still can be.
- Report rows have a little more room, and the unread mark sits on the corner of the app's icon instead of in the margin.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.5.3-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
