Xrash 0.4.10 updates icli and adds a test for report bundles. Nothing changes in how the app behaves.

- A new test checks that a report bundle keeps a file name that is not plain ASCII, such as `フィラ-Café-2026-09-08.ips`, when it is written and read back, and that the name is marked as UTF-8 so other zip tools read it correctly. Xrash already handled such names; the test keeps it that way.
- The system-state tools come from icli 0.7.5. It frees the replies launchd sends back after each query, which it previously kept for as long as the process ran.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.4.10-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
