Xrash 0.4.15 is built with icli 0.7.14.

- A process or memory entry whose name is not valid UTF-8 no longer stops the system state from loading. icli put such a name into its result as nothing, which ended the process reading it instead of reporting an error.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.4.15-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
