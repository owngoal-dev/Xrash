Xrash 0.4.9 checks every build against the oldest iOS it supports before it is packaged. Nothing changes in how the app behaves.

- Before a package is made, the build is now checked for any part of the Swift runtime that iOS 15 does not have. A build that needs something newer is refused rather than shipped, so an update cannot stop Xrash from opening on an older version of iOS.

The macOS app is ad-hoc signed; after unzipping, clear the quarantine bit once: `xattr -dr com.apple.quarantine Xrash.app`.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless firmware, and `Xrash-0.4.9-macos.zip` for a Mac. SHA-256 checksums are included in `SHA256SUMS`.
